# Design tokens

Every value below is read **live from the CSS custom properties** that `src/styles/base/_root.scss`
generates from the Sass maps in `src/styles/abstracts/_tokens.scss`. The page can't drift from the code.
The values are defined once in `src/styles/abstracts/_tokens.scss`. See `docs/DESIGN.md` for how they are used and the accessibility adjustments.

## Gradients

`brand` is the signature blue→turquoise gradient and is used for display text and accents.
`action` is the same hue, deepened so white button labels pass WCAG AA (≥ 4.5:1).
