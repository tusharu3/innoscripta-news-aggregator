# Design tokens

Every value below is read **live from the CSS custom properties** that `src/styles/base/_root.scss`
generates from the Sass maps in `src/styles/abstracts/_tokens.scss`. The page can't drift from the code.
The values come from innoscripta.com's own `:root` variables. See `docs/DESIGN.md` for where each one comes from and the accessibility adjustments.

## Gradients

`brand` is innoscripta's signature blue→turquoise and is used for display text and accents.
`action` is the same hue, deepened so white button labels pass WCAG AA (≥ 4.5:1).

## Typography

Poppins, the typeface innoscripta uses, self-hosted through `@fontsource/poppins`. Styles marked _fluid_ scale with `clamp()` between 576px and 1280px viewports.
